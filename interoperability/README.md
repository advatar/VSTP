# Interoperability Bridges

This directory stores concrete export/import bridges from external systems into VSTP.

Current bridge artifacts:

- `activechain/bridge.md` — design and mapping document for ActiveChain/Actum transitions.
- `activechain/actum_to_vstp.py` — converter from ActiveChain action export to VSTP bundle.
- `activechain/actum-action-export.json` — sample ActiveChain export input.
- `activechain/actum-keyring.json` — sample verifier keyring used by the converter.
- `activechain/example-vstp-transition.json` — sample converter output.

Profiles:

- `profiles/actum-01.md` — `urn:vstp:actum:v1` profile draft for ActiveChain interop.
